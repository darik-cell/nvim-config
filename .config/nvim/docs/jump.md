# Прыжки по тексту

Flash ищет по видимому тексту во всех доступных для фокуса окнах текущей вкладки Neovim.

1. В Normal mode нажми `Пробел`, затем `f` (или `а` в русской раскладке).
2. Введи символ нужного текста: например, `e` для `environments.yaml`.
3. Рядом с совпадениями появятся голубые метки из двух заглавных букв.
   Введи обе буквы метки у нужного места строчными, без Shift.
   После первой буквы останутся метки выбранной группы; после второй произойдёт переход.
   `Esc` отменяет прыжок на любом этапе.

Поиск работает и между панелями с файлами и выводом терминала. В терминале сначала нажми
`jj` или `оо`, чтобы выйти в Normal mode. Прыжок перемещает курсор Neovim по выводу,
а для возврата к вводу в терминале нажми `i`.

Скрытые панели и другие вкладки не участвуют в поиске. В русской раскладке команда
запускается через `Пробел → а`, но для ввода латинских букв меток переключись на английскую.

`Пробел → f` запускает Flash сразу, без ожидания продолжения комбинации.

Метки занимают свободное место справа от совпадения, а если там тесно — слева.
Найденные символы остаются видимыми; текст и строки не сдвигаются. У слишком близких
совпадений часть меток скрывается, чтобы подсказки не перекрывались. Если у нужного места
нет метки, введи более длинный текст поиска. После прыжка или отмены метки исчезают.
Для прыжка внутрь свёрнутого блока сначала раскрой его.

При более чем 676 совпадениях введи ещё символы поиска, чтобы сузить результат.
