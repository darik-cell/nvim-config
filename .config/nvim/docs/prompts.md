# Черновики промптов

`Ctrl+G` в терминале открывает черновик именно этого терминала — с Codex,
Nessy или любой другой программой. Повторное нажатие возвращает тот же буфер,
пока промпт не отправлен через `QQ` и Enter. В normal и insert вне терминала
открывается черновик текущего файла промпта или последней выбранной сессии вкладки.

`QQ` вставляет текст в исходный терминал промпта; Enter для отправки нажимается вручную.
Связка работает с любой программой в этом терминале и не зависит от Codex.
Только после Enter в том же терминале следующий `Ctrl+G` создаёт новый
черновик. Одна вставка через `QQ` сохраняет текущий буфер. `Ctrl+C` отменяет
ожидание отправки; после него для завершения черновика нужно снова нажать `QQ` и Enter.
Если терминал не запущен, вставка или передача Enter не удалась, черновик сохраняется.
Если после `QQ` изменён текст в буфере промпта, перед отправкой нужна повторная вставка
через `QQ`. После восстановления nvim из снимка связку также нужно повторить.

Файлы создаются с прежними именами: `21-октября-СР-12:30.md`.
При совпадении имени добавляются суффиксы `-01`, `-02` и далее.
Для терминала из `~/work/test` каталог будет
`/tmp/work/test/session-<id>/`. Все его промпты остаются в этой папке,
а другой терминал получает собственную сессию. Папка фиксируется при первом
`Ctrl+G`; рабочий каталог берётся у процесса терминала.
Для каталогов вне домашней папки используется `/tmp/_outside-home/<полный-путь>/session-<id>/`.

Просмотр отправленного файла не заменяет текущий черновик. Восстановление
после сбоя сохраняет черновики, их каталоги и связь с восстановленными терминалами.
Временные файлы могут быть удалены системой при очистке `/tmp`.

`<leader>gp` открывает отдельный Markdown-буфер без файла, один на вкладку nvim.
Уход из буфера сохраняет его текст; повторное нажатие открывает тот же буфер.
Закрытие вкладки, включая `tabonly`, полностью удаляет буфер вместе с текстом.
При аварийном завершении его текст восстанавливается вместе с вкладкой.
