# Черновики промптов

`<leader>ga` (или `<leader>пф` в русской раскладке) открывает только терминал
агента в normal mode для прокрутки вывода.

`Ctrl+G` (или `Ctrl+П` в русской раскладке) показывает или прячет черновик
исходного терминала — с Codex, Nessy или любой другой программой. Если черновик
скрыт, справа открывается вертикальный сплит с ним, терминал остаётся слева.
Если черновик уже виден, он сохраняется, сплит закрывается и фокус возвращается
в исходный терминал независимо от того, где находился фокус. Курсор и прокрутка
окна агента сохраняются при открытии и закрытии сплита. При открытии из normal
mode после перерисовки терминала сохраняется текстовое место под курсором,
даже если изменились переносы и номера строк. При открытии из режима ввода
сохраняется положение на актуальном экране относительно конца терминала:
пустое поле ввода и повторяющиеся рамки Pi не вызывают переход в начало истории.
Прокрутка пользователя отменяет ожидание восстановления позиции. Если агент был в normal
mode для чтения вывода, сохраняется этот режим; если был в режиме ввода,
возвращается ввод. После `QQ/ЙЙ` всегда включается ввод для отправки текста.
Клавиша работает
в normal, insert и режиме ввода терминала. Повторное открытие возвращает тот же
текст, пока он не отправлен через `QQ/ЙЙ` и Enter.

`Ctrl+W W` переключает между уже открытыми терминалом и черновиком в normal mode:
у агента можно сразу листать вывод, а для ввода нажать `i`.
Переключение работает и из insert черновика, и из ввода терминала;
доступна русская раскладка `Ctrl+Ц Ц`. Если черновик скрыт, эта клавиша его не открывает.

`QQ/ЙЙ` сохраняет текст в прежнем файле, вставляет его в исходный терминал
и переводит туда фокус в режим ввода. Сплит черновика сразу закрывается.
После Enter в том же терминале черновик считается отправленным;
новый пустой файл появится только при следующем `Ctrl+G`. Enter сам сплит не открывает.
Связка работает с любой программой в этом терминале и не зависит от Codex.
Enter без предварительного `QQ/ЙЙ` не заменяет черновик. `Ctrl+C` отменяет
ожидание отправки; для нового черновика потребуется снова `QQ/ЙЙ` и Enter.
Если текст изменён после вставки, перед Enter нужна повторная вставка через `QQ/ЙЙ`.
Если сохранить текст или вставить его в терминал не удалось, черновик остаётся
открытым. Просмотр и повторная вставка старого файла не заменяют текущий черновик.

Файлы создаются с прежними именами: `21-октября-СР-12:30.md`.
При совпадении имени добавляются суффиксы `-01`, `-02` и далее.
Для терминала из `~/work/test` каталог будет
`/tmp/work/test/session-<id>/`. Все его промпты остаются в этой папке,
а другой терминал получает собственную сессию. Папка фиксируется при первом
`Ctrl+G`; рабочий каталог берётся у процесса терминала.
Для каталогов вне домашней папки используется `/tmp/_outside-home/<полный-путь>/session-<id>/`.

Просмотр отправленного файла не заменяет текущий черновик. Восстановление
после сбоя сохраняет черновики, их каталоги и связь с восстановленными терминалами.
Временные файлы могут быть удалены системой при очистке `/tmp`.

`<leader>gp` открывает отдельный Markdown-буфер без файла, один на вкладку nvim.
Уход из буфера сохраняет его текст; повторное нажатие открывает тот же буфер.
Закрытие вкладки, включая `tabonly`, полностью удаляет буфер вместе с текстом.
При аварийном завершении его текст восстанавливается вместе с вкладкой.
